OpticalModelingToolkit.jl

OpticalModelingToolkit (OMTK) adds an optical domain to ModelingToolkit: mirrors, beamsplitters, free space, lasers and photodetectors that compose with connect like any other MTK component. They therefore share one model with mechanics, electronics and control loops, and solve with the SciML stack.

The scope is plane-wave (TEM₀₀) optics on the slowly-varying complex envelope: DC operating points, small-signal transfer functions, time-domain transients, and exact frequency-domain responses.

A Fabry-Perot cavity

using OpticalModelingToolkit, ModelingToolkit, NonlinearSolve
using ModelingToolkit: t_nounits as t

@named laser = Laser(A = 1.0)
@named m1 = Mirror(R = 0.99)
@named space = FreeSpace(L = 1064e-9 / 4)   # on resonance
@named m2 = Mirror(R = 0.999)
@named pd = Photodetector()

eqs = [link(laser.p1, m1.p1); link(m1.p2, space.p1); link(space.p2, m2.p1); link(m2.p2, pd.p1)]
@named cavity = System(eqs, t; systems = [laser, m1, space, m2, pd])

sys = mtkcompile(cavity)
sol = solve(NonlinearProblem(sys, Dict(u => 0.0 for u in unknowns(sys))))
sol[pd.P]    # transmitted power

From the same model:

  • Transfer functions: linearize_proper(cavity, inputs, outputs) returns a proper (A, B, C, D). Hand it to ControlSystemsBase.ss for freqresp, bodeplot, poles and so on.
  • Exact frequency response: to_scattering(cavity) returns the cavity with every free-space delay kept as an exact e^{-sτ}.
  • Delay dynamics in the time domain: rebuild with FreeSpace(rep = PadeDelay(n)).
