OpticalModelingToolkit.Algebraic — Type
Algebraic()

Propagation as the static phase rotation e^{ikL}, with no dynamics and no states. Exact at DC; the right default for audio-band studies of short cavities where every analysis frequency is far below c/L.

source
OpticalModelingToolkit.OpticalComponent — Type
OpticalComponent

System-metadata key under which every optical component records its role in the scattering network. to_scattering reads it to lower a composed model; the value is one of

  • Scatterer: a static linear map between ports,
  • Propagator: a two-port delay with a phase rotation,
  • Terminal: a one-port source or sink, which becomes an external channel.

A new component joins the frequency-domain lowering by setting this metadata.

source
OpticalModelingToolkit.PadeDelay — Type
PadeDelay(order)

Order-n all-pass rational approximation of the free-space delay e^{-sτ}, τ = L/c: a cascade of order first-order all-pass sections

H₁(s) = (1 - sθ/2)/(1 + sθ/2),    θ = τ/order

applied to the complex envelope after the static rotation e^{ikL}. |H₁(iω)| ≡ 1 exactly, so passivity holds at every order; only the phase is approximate (error ~(ωθ)³/12 per section, total ∝ order⁻² at fixed ωτ). Cavity FSR physics becomes representable once order ≳ ωτ across the band of interest. Costs 4·order real states per FreeSpace (two quadratures, two directions).

source
OpticalModelingToolkit.PropagationRep — Type
PropagationRep

How FreeSpace propagation is represented in the time domain. Passed to FreeSpace(rep = ...) and threaded down from the top of a model, so switching a whole model between representations is a one-argument change per analysis:

  • Algebraic: static phase rotation, the adiabatic limit.
  • PadeDelay: order-n all-pass rational approximation of the delay.

For frequency-domain questions that need the exact transcendental delay, do not rationalize at all: lower the model with to_scattering.

OpticalModelingToolkit.Terminal — Type
Terminal()

Role of a one-port (p1) source or sink. In the scattering form, the field it emits is an external input channel and the field it receives is an external output channel, both named after the component.

OpticalModelingToolkit.Beamsplitter — Method
Beamsplitter(; R = 0.5, T = 1 - R)

Four-port beamsplitter. p1 and p2 are on the front face and reflect into each other with +√R; p3 and p4 are on the back face and reflect into each other with -√R. Transmission (√T) couples p1 ↔ p3 and p2 ↔ p4.

source
OpticalModelingToolkit.FreeSpace — Method
FreeSpace(; L = 1.0, λ = 1064e-9, c = 299792458.0, rep = Algebraic())

Free-space propagation over length L between ports p1 and p2, in both directions: out(t) = e^{ikL} in(t - L/c) with k = 2π/λ. The rotation is kept exact; rep (a PropagationRep) chooses how the delay is realized.

OpticalModelingToolkit.Laser — Method
Laser(; A = 1.0, ϕ = 0.0)

Emits the constant envelope A e^{iϕ} from p1 and absorbs whatever arrives.

source
OpticalModelingToolkit.LaserModulated — Method
LaserModulated(; A = 1.0, ϕ = 0.0)

A Laser whose envelope (A + δA + i δQ) e^{iϕ} carries small-signal modulation inputs: δA in phase with the carrier (amplitude modulation) and δQ in quadrature (phase modulation, to first order). Both are [input = true] variables: bind them with equations or name them as linearization inputs, where together they span the full quadrature pair.

source
OpticalModelingToolkit.Mirror — Method
Mirror(; R = 0.99, T = 1 - R)

Two-port mirror with power reflectivity R and transmissivity T, lossy when R + T < 1. Reflection is +√R on the p1 face and -√R on the p2 face; transmission is √T both ways.

source
OpticalModelingToolkit.MovableMirror — Method
MovableMirror(; R = 0.99, T = 1 - R, λ = 1064e-9, c = 299792458.0)

A Mirror with a microscopic longitudinal position x (an [input = true] variable, positive toward the p2 side) and the radiation pressure force F it feels (an [output = true] variable, positive toward the p2 side). Bind x with an equation, e.g. to a mechanical model driven by F, or name it as a linearization input.

Moving by x lengthens the p1-side round trip and shortens the p2-side one: the p1 reflection picks up e^{+2ikx} and the p2 reflection e^{-2ikx}. The full nonlinear dependence is kept, so a length-control loop can sweep through fringes. With field amplitudes in √W, the force is

F = (|p1.i|² + |p1.o|² - |p2.i|² - |p2.o|²) / c.

At x = 0 the scattering is exactly that of Mirror.

OpticalModelingToolkit.linearize_proper — Method
linearize_proper(model, inputs, outputs; op = Dict(), t = 0.0, kwargs...)
    -> (; A, B, C, D), simplified_sys

Numerically linearize model between inputs and outputs at the operating point op, returning a proper state-space realization whose states are exactly the differential unknowns: index-1 algebraic variables (torn circulating-field loops) are eliminated statically instead of being kept as states behind differentiated constraints, so no input-derivative columns appear and the realization is regular at s = 0 (dcgain is exact).

Feed the matrices straight into ControlSystemsBase:

mats, _ = linearize_proper(model, [laser.δA, laser.δQ], [pd.P])
sys = ss(mats...)
freqresp(sys, ωs)    # bodeplot, poles, dcgain, …

Keyword arguments are forwarded to ModelingToolkit.linearization_function.

OpticalModelingToolkit.to_scattering — Method
to_scattering(model::System) -> NamedTuple

Lower a composed (not yet mtkcompiled) optical model to the canonical transcendental scattering form. Returns (M1, M2, M3, M4, delays, x, u, y), field for field the contents of an Etalon ScatteringSystem, so that

G(s) = M3 * ((Diagonal(exp.(s .* delays)) - M1) \ M2) + M4

is the exact transfer matrix from the external inputs u to the external outputs y, FSR physics included. With Etalon loaded, Etalon.ScatteringSystem(model) wraps this directly.

The lowering works on the scalar complex amplitude and reads only the OpticalComponent metadata of each component: x indexes directed edges, each Propagator (FreeSpace) collapses into an exact delay on its edges with its rotation folded into the next matrix entry, and each Terminal (Laser, Vacuum, Photodetector, …) contributes one input and one output channel named after it. Any PropagationRep is ignored; the delays here are exact. Components scatter at their constructor values (a MovableMirror at x = 0).

Requires a flat model: all components and link/connect equations at the top level, and every optical port wired.
