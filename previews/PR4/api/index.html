OpticalModelingToolkit.Algebraic — Type
Algebraic()

Propagation as instantaneous transfer, with no dynamics and no states. Exact at DC; the right default for audio-band studies of short cavities where every analysis frequency is far below c/L.

source
OpticalModelingToolkit.OpticalComponent — Type
OpticalComponent

System-metadata key under which every optical component records its role in the scattering network. to_scattering reads it to lower a composed model; the value is one of

  • Scatterer: a static linear map between ports,
  • Propagator: a two-port delay with a phase rotation,
  • Terminal: a one-port source or sink, which becomes an external channel.

A new component joins the frequency-domain lowering by setting this metadata.

source
OpticalModelingToolkit.PadeDelay — Type
PadeDelay(order)

Order-n all-pass rational approximation of the free-space delay e^{-sτ}, τ = L/c: a cascade of order first-order all-pass sections

H₁(s) = (1 - sθ/2)/(1 + sθ/2),    θ = τ/order

applied to the complex envelope. |H₁(iω)| ≡ 1 exactly, so passivity holds at every order; only the phase is approximate (error ~(ωθ)³/12 per section, total ∝ order⁻² at fixed ωτ). Cavity FSR physics becomes representable once order ≳ ωτ across the band of interest. Costs 4·order real states per FreeSpace (two quadratures, two directions).

source
OpticalModelingToolkit.PropagationRep — Type
PropagationRep

How FreeSpace propagation is represented in the time domain. Passed to FreeSpace(rep = ...) and threaded down from the top of a model, so switching a whole model between representations is a one-argument change per analysis:

  • Algebraic: static phase rotation, the adiabatic limit.
  • PadeDelay: order-n all-pass rational approximation of the delay.

For frequency-domain questions that need the exact transcendental delay, do not rationalize at all: lower the model with to_scattering.

Terminal()

Role of a one-port (p1) source or sink. In the scattering form, the field it emits is an external input channel and the field it receives is an external output channel, both named after the component.

OpticalModelingToolkit.Beamsplitter — Method
Beamsplitter(; R = 0.5, T = 1 - R, ϕ = 0)

Four-port beamsplitter. p1 and p2 are on the reflective face and reflect into each other with +√R e^{2iϕ}; p3 and p4 are on the back face and reflect into each other with -√R e^{-2iϕ}. Transmission (√T) couples p1 ↔ p3 and p2 ↔ p4.

source
OpticalModelingToolkit.FreeSpace — Method
FreeSpace(; L = 1.0, c = 299792458.0, rep = Algebraic())

Free-space propagation over the macroscopic length L between ports p1 and p2, in both directions: the envelope is delayed, out(t) = in(t - L/c). The carrier phase is a whole number of wavelengths; set microscopic offsets with the tuning ϕ of a mirror. rep (a PropagationRep) chooses how the delay is realized.

OpticalModelingToolkit.Laser — Method
Laser(; A = 1.0, ϕ = 0.0)

Emits the constant envelope A e^{iϕ} from p1 and absorbs whatever arrives.

source
OpticalModelingToolkit.LaserModulated — Method
LaserModulated(; A = 1.0, ϕ = 0.0)

A Laser whose envelope (A + δA + i δQ) e^{iϕ} carries small-signal modulation inputs: δA in phase with the carrier (amplitude modulation) and δQ in quadrature (phase modulation, to first order). Both are [input = true] variables: bind them with equations or name them as linearization inputs, where together they span the full quadrature pair.

source
OpticalModelingToolkit.Mirror — Method
Mirror(; R = 0.99, T = 1 - R, ϕ = 0)

Two-port mirror with power reflectivity R and transmissivity T, lossy when R + T < 1. p1 is the reflective face: it reflects with +√R e^{2iϕ}, the p2 face with -√R e^{-2iϕ}, and transmission is √T both ways. The tuning ϕ = kΔx [rad] is a microscopic displacement Δx toward p2.

source
OpticalModelingToolkit.MovableMirror — Method
MovableMirror(; R = 0.99, T = 1 - R, ϕ = 0, λ = 1064e-9, c = 299792458.0)

A Mirror with a microscopic longitudinal position x (an [input = true] variable, positive toward the p2 side) and the radiation pressure force F it feels (an [output = true] variable, positive toward the p2 side). Bind x with an equation, e.g. to a mechanical model driven by F, or name it as a linearization input.

The position adds to the tuning: the mirror scatters as a Mirror with tuning ϕ + 2πx/λ. The full nonlinear dependence is kept, so a length-control loop can sweep through fringes. With field amplitudes in √W, the force is

F = (|p1.i|² + |p1.o|² - |p2.i|² - |p2.o|²) / c.

OpticalModelingToolkit.expose — Method
expose(outer, inner) -> Vector{Equation}

Inside a subassembly, make the port inner of one of its components available as the subassembly's own port outer: the field arriving at outer passes in to inner, and the field leaving inner passes out through outer.

@component function Cavity(; name, L)
    @named m1 = Mirror(); @named space = FreeSpace(; L); @named m2 = Mirror()
    @named p1 = OpticalPort(); @named p2 = OpticalPort()
    eqs = [expose(p1, m1.p1); link(m1.p2, space.p1); link(space.p2, m2.p1); expose(p2, m2.p2)]
    return System(eqs, t; name, systems = [m1, space, m2, p1, p2])
end

OpticalModelingToolkit.linearize_proper — Method
linearize_proper(model, inputs, outputs; op = Dict(), t = 0.0, kwargs...)
    -> (; A, B, C, D), simplified_sys

Numerically linearize model between inputs and outputs at a steady state, returning a proper state-space realization whose states are exactly the differential unknowns. Index-1 algebraic variables (the circulating fields) are eliminated statically instead of being kept as states behind differentiated constraints, so no input-derivative columns appear and the realization is regular at s = 0 (dcgain is exact).

op sets inputs, parameters and any differential states to hold fixed; every other differential state is solved for steady state (ẋ = 0). If those states have no unique steady state (a free integrator, a free mass), pin them in op.

Feed the matrices straight into ControlSystemsBase:

mats, _ = linearize_proper(model, [laser.δA, laser.δQ], [pd.P])
sys = ss(mats...)
freqresp(sys, ωs)    # bodeplot, poles, dcgain, …

Keyword arguments are forwarded to ModelingToolkit.linearization_function.

OpticalModelingToolkit.to_scattering — Method
to_scattering(model::System) -> NamedTuple

Lower a composed (not yet mtkcompiled) optical model to the canonical transcendental scattering form. Returns (M1, M2, M3, M4, delays, x, u, y), field for field the contents of a Breadboard ScatteringSystem, so that

G(s) = M3 * ((Diagonal(exp.(s .* delays)) - M1) \ M2) + M4

is the exact transfer matrix from the external inputs u to the external outputs y, FSR physics included. With Breadboard loaded, Breadboard.ScatteringSystem(to_scattering(model)...) gives its solvers and pade rationalization.

The lowering works on the scalar complex amplitude and reads only the OpticalComponent metadata of each component: x indexes directed edges, each Propagator (FreeSpace) collapses into an exact delay on its edges, and each Terminal (Laser, Vacuum, Photodetector, …) contributes one input and one output channel named after it. Any PropagationRep is ignored; the delays here are exact. Components scatter at their constructor values (a MovableMirror at x = 0).

Subassemblies are flattened: a subsystem without OpticalComponent metadata is searched for optical components, and its own ports may pass fields through to them (connect(p1.i, m1.p1.i), connect(m1.p1.o, p1.o)). Components are named by their full path, e.g. Symbol("cavity₊m1"). Non-optical subsystems and equations are ignored. Every optical port of every component must be wired.
